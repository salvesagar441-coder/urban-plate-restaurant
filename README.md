# Urban Plate — Modern American Kitchen & Bar

A professional, fully responsive single-page restaurant website built with HTML5, CSS3, and vanilla JavaScript.

![Urban Plate](https://images.unsplash.com/photo-1550966871-3ed3cdb51f3a?w=1200&h=400&fit=crop&q=80)

## Features

- **Responsive Design** — Mobile-first layout with breakpoints at 1024px, 900px, 600px, and 380px
- **Smooth Navigation** — Sticky navbar with scroll-aware styling and active link highlighting
- **Interactive Menu** — Tabbed menu with 4 categories: Starters, Main Course, Desserts, and Drinks
- **Image Gallery** — Masonry-style photo grid with hover effects
- **Scroll Animations** — Subtle reveal animations powered by IntersectionObserver
- **Mobile Menu** — Full-screen overlay with staggered link animations
- **Contact Integration** — Click-to-call, email, and WhatsApp CTAs
- **Professional Footer** — Brand info, navigation links, social media, and legal links

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Flexbox, Grid, transitions, and animations
- **JavaScript** — Vanilla JS (no frameworks or dependencies)
- **Fonts** — Playfair Display + Inter (Google Fonts)
- **Images** — High-quality photography via Unsplash

## Getting Started

Simply open `index.html` in a browser — no build tools or server required.

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/urban-plate-restaurant.git

# Open in browser
open index.html
```
